# Prompt 02.1 — Estrutura do Projeto FastAPI e Dockerfile do Backend

> **Ordem de implementação:** Primeiro sub-prompt do backend. Implemente após todo o modelo de dados (01.1–01.4) e antes dos demais prompts do backend (02.2–02.6).

---

## Objetivo

Configurar a estrutura base do projeto FastAPI, o `Dockerfile` do backend e os arquivos de configuração necessários para rodar a API dentro de um contêiner Docker.

---

## Contexto

O backend usa **Python 3.12** com **FastAPI** e **Uvicorn**. Os modelos de dados já existem (Prompts 01.x). Este prompt cria o esqueleto da aplicação: `main.py`, `requirements.txt`, `Dockerfile` e configuração de CORS. O `docker-compose.yml` já foi criado no Prompt 00.

---

## Escopo

Esta tarefa cobre **exclusivamente**:

- `backend/Dockerfile`
- `backend/requirements.txt`
- `backend/app/__init__.py`
- `backend/app/main.py` — instância FastAPI, CORS, evento startup, rota `/health`
- `backend/app/core/__init__.py`
- `backend/app/core/config.py` — leitura de variáveis de ambiente
- `backend/tests/__init__.py`

---

## Restrições

> ⚠️ **Não altere nada além do que está descrito neste prompt.**
> Não implemente rotas de negócio (autenticação, estoque, empréstimos, chat). Não crie componentes de frontend. Não modifique os modelos de dados.

- Imagem base: **`python:3.12-slim`**.
- O `main.py` deve chamar `init_db()` e `seed_estoque()` no evento `lifespan` (startup).
- CORS deve permitir origem `*` em desenvolvimento (configurável via env `CORS_ORIGINS`).
- A rota `GET /health` deve retornar `{"status": "ok"}` sem autenticação.
- O servidor deve rodar com `uvicorn app.main:app --host 0.0.0.0 --port 8000`.
- Todos os segredos lidos via `python-dotenv` + `os.getenv`.

### `backend/Dockerfile`

```dockerfile
FROM python:3.12-slim

WORKDIR /app

# Instalar dependências do sistema
RUN apt-get update && apt-get install -y --no-install-recommends \
    gcc \
    && rm -rf /var/lib/apt/lists/*

# Copiar e instalar dependências Python
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copiar código da aplicação
COPY app/ ./app/

# Diretório usado pelo fallback SQLite local (o Docker usa PostgreSQL via DATABASE_URL)
RUN mkdir -p /app/data

EXPOSE 8000

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### `backend/app/core/config.py`

```python
import os
from dotenv import load_dotenv

load_dotenv()

GEMINI_API_KEY: str = os.getenv("GEMINI_API_KEY", "")
JWT_SECRET: str = os.getenv("JWT_SECRET", "dev-secret-change-in-production")
JWT_ALGORITHM: str = "HS256"
JWT_EXPIRE_MINUTES: int = int(os.getenv("JWT_EXPIRE_MINUTES", "480"))  # 8h
ADMIN_USER: str = os.getenv("ADMIN_USER", "admin")
ADMIN_PASSWORD: str = os.getenv("ADMIN_PASSWORD", "")
DATABASE_DIR: str = os.getenv("DATABASE_DIR", "data")
CORS_ORIGINS: list[str] = os.getenv("CORS_ORIGINS", "*").split(",")
```

### `backend/app/main.py`

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from app.core.config import CORS_ORIGINS
from app.database.init_db import init_db
from app.database.seed_estoque import seed_estoque


@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup: inicializar bancos e seed
    init_db()
    seed_estoque()
    yield
    # Shutdown: nada a fazer por enquanto


app = FastAPI(
    title="Empresta Lab API",
    description="API para controle de empréstimo de equipamentos de laboratório.",
    version="1.0.0",
    lifespan=lifespan,
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=CORS_ORIGINS,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/health", tags=["Infra"])
def health_check():
    return {"status": "ok"}
```
