# Prompt 02.2 — Autenticação JWT do Backend

> **Ordem de implementação:** Segundo sub-prompt do backend. Implemente após 02.1 (estrutura) e antes de 02.3–02.6.

---

## Objetivo

Implementar o sistema de autenticação do Empresta Lab, com dois perfis separados:
- **Cliente** — autenticado por matrícula + senha.
- **Administrador** — autenticado por usuário + senha (credenciais via variável de ambiente).

Ambos recebem **tokens JWT** com claims de role para autorização nas demais rotas.

---

## Contexto

A estrutura FastAPI já existe (Prompt 02.1). O modelo `Cliente` (tabela `clientes` em `emprestimos.db`) já foi definido (Prompt 01.2). Este prompt adiciona:
- Senha hasheada na tabela `clientes` (coluna `senha_hash`).
- Endpoints de login e registro.
- Funções utilitárias de JWT e hash.
- Dependencies FastAPI para proteger rotas por role (`cliente` ou `admin`).

---

## Restrições

> ⚠️ **Não altere nada além do que está descrito neste prompt.**
> Não implemente endpoints de estoque, empréstimos ou chat. Não modifique o Dockerfile, docker-compose ou frontend.

- Usar **`passlib[bcrypt]`** para hash de senha.
- Usar **`python-jose[cryptography]`** para geração e validação de JWT.
- O token deve conter os claims: `sub` (matrícula ou username), `role` (`"cliente"` ou `"admin"`), `exp`.
- O admin **não tem tabela no banco** — suas credenciais vêm das env vars `ADMIN_USER` e `ADMIN_PASSWORD` definidas em `config.py`.
- O endpoint `POST /auth/cliente/register` cria o cliente na tabela `clientes` com senha hasheada.
- Rotas protegidas devem retornar **401** para token ausente e **403** para role incorreta.

## Arquivos a Criar/Modificar

### `backend/app/core/security.py`

```python
from datetime import datetime, timedelta, timezone
from jose import JWTError, jwt
from passlib.context import CryptContext
from app.core.config import JWT_SECRET, JWT_ALGORITHM, JWT_EXPIRE_MINUTES

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")


def hash_password(password: str) -> str:
    return pwd_context.hash(password)


def verify_password(plain: str, hashed: str) -> bool:
    return pwd_context.verify(plain, hashed)


def create_token(sub: str, role: str) -> str:
    expire = datetime.now(timezone.utc) + timedelta(minutes=JWT_EXPIRE_MINUTES)
    payload = {"sub": sub, "role": role, "exp": expire}
    return jwt.encode(payload, JWT_SECRET, algorithm=JWT_ALGORITHM)


def decode_token(token: str) -> dict:
    return jwt.decode(token, JWT_SECRET, algorithms=[JWT_ALGORITHM])
```

### `backend/app/dependencies.py`

```python
from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
from jose import JWTError
from app.core.security import decode_token

bearer_scheme = HTTPBearer()


def get_current_user(credentials: HTTPAuthorizationCredentials = Depends(bearer_scheme)) -> dict:
    try:
        payload = decode_token(credentials.credentials)
        return payload
    except JWTError:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Token inválido ou expirado.")


def get_current_cliente(payload: dict = Depends(get_current_user)) -> dict:
    if payload.get("role") != "cliente":
        raise HTTPException(status_code=status.HTTP_403_FORBIDDEN, detail="Acesso restrito a clientes.")
    return payload


def get_current_admin(payload: dict = Depends(get_current_user)) -> dict:
    if payload.get("role") != "admin":
        raise HTTPException(status_code=status.HTTP_403_FORBIDDEN, detail="Acesso restrito a administradores.")
    return payload
```

### `backend/app/routers/auth.py`

```python
from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.orm import Session
from app.database.emprestimos_db import get_emprestimos_db
from app.models.emprestimos import Cliente
from app.schemas.auth import ClienteLogin, ClienteRegister, AdminLogin, TokenResponse
from app.core.security import hash_password, verify_password, create_token
from app.core.config import ADMIN_USER, ADMIN_PASSWORD

router = APIRouter(prefix="/auth", tags=["Autenticação"])


@router.post("/cliente/register", status_code=status.HTTP_201_CREATED)
def registrar_cliente(body: ClienteRegister, db: Session = Depends(get_emprestimos_db)):
    if db.query(Cliente).filter_by(matricula=body.matricula).first():
        raise HTTPException(status_code=400, detail="Matrícula já cadastrada.")
    cliente = Cliente(
        nome=body.nome,
        email=body.email,
        telefone=body.telefone,
        matricula=body.matricula,
        senha_hash=hash_password(body.senha),
    )
    db.add(cliente)
    db.commit()
    return {"mensagem": "Cliente cadastrado com sucesso."}


@router.post("/cliente/login", response_model=TokenResponse)
def login_cliente(body: ClienteLogin, db: Session = Depends(get_emprestimos_db)):
    cliente = db.query(Cliente).filter_by(matricula=body.matricula).first()
    if not cliente or not verify_password(body.senha, cliente.senha_hash):
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Credenciais inválidas.")
    token = create_token(sub=cliente.matricula, role="cliente")
    return TokenResponse(access_token=token)


@router.post("/admin/login", response_model=TokenResponse)
def login_admin(body: AdminLogin):
    if body.usuario != ADMIN_USER or body.senha != ADMIN_PASSWORD:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Credenciais de admin inválidas.")
    token = create_token(sub=ADMIN_USER, role="admin")
    return TokenResponse(access_token=token)
```

## Critérios de Aceite

- [ ] `POST /auth/cliente/register` cria cliente com senha hasheada e retorna 201.
- [ ] `POST /auth/cliente/login` com credenciais corretas retorna token JWT com `role: "cliente"`.
- [ ] `POST /auth/cliente/login` com senha errada retorna 401.
- [ ] `POST /auth/admin/login` com credenciais corretas retorna token JWT com `role: "admin"`.
- [ ] `POST /auth/admin/login` com credenciais erradas retorna 401.
- [ ] Rotas protegidas com `get_current_admin` retornam 403 para token de cliente.
- [ ] Senhas nunca são armazenadas em texto plano.
- [ ] Tokens expiram em **15 minutos** (`JWT_EXPIRE_MINUTES=15`, configurável por ambiente):
      após esse período (ou inatividade), o usuário deve fazer login novamente.
