# Prompt 01.1 — Schema do Banco de Estoque (`estoque.db`)

> **Ordem de implementação:** Primeiro sub-prompt do modelo de dados. Implemente antes do 01.2 (schema de empréstimos), 01.3 (seed) e 01.4 (testes).

---

## Objetivo

Definir o modelo SQLAlchemy e a configuração de sessão para o banco `estoque.db`, que armazena os equipamentos disponíveis para empréstimo no laboratório.

---

## Contexto

O projeto usa dois bancos SQLite separados. Este prompt cobre exclusivamente o banco `estoque.db`. No ambiente Docker, os arquivos `.db` são armazenados em `/app/data/` (volume persistente); localmente, em `backend/data/`. O SQLAlchemy deve ler o caminho do banco a partir da variável de ambiente `DATABASE_DIR`.

---

## Escopo

Esta tarefa cobre **exclusivamente**:

- O arquivo `backend/app/models/estoque.py` — model SQLAlchemy `Equipamento`.
- O arquivo `backend/app/database/estoque_db.py` — engine, sessão e base declarativa para `estoque.db`.

---

## Restrições

> ⚠️ **Não altere nada além do que está descrito neste prompt.**
> Não crie rotas, endpoints, lógica de negócio, modelos de `emprestimos.db`, scripts de seed, testes ou qualquer outro artefato.

- O caminho do banco deve ser construído como: `os.path.join(os.getenv("DATABASE_DIR", "data"), "estoque.db")`.
- Usar **SQLAlchemy 2.x** com estilo declarativo (`DeclarativeBase`).
- O constraint `CHECK (quantidade >= 0)` deve ser definido via `CheckConstraint` no modelo.
- Não usar `alembic` — a criação das tabelas será feita via `Base.metadata.create_all()` no script de inicialização (Prompt 01.3).
- Não incluir lógica de autenticação, hashing ou JWT.

## Arquivos a Criar

### `backend/app/database/estoque_db.py`

```python
import os
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, DeclarativeBase

DATABASE_DIR = os.getenv("DATABASE_DIR", "data")
os.makedirs(DATABASE_DIR, exist_ok=True)

ESTOQUE_DATABASE_URL = f"sqlite:///{os.path.join(DATABASE_DIR, 'estoque.db')}"

estoque_engine = create_engine(
    ESTOQUE_DATABASE_URL,
    connect_args={"check_same_thread": False},
)

EstoqueSession = sessionmaker(autocommit=False, autoflush=False, bind=estoque_engine)

class EstoqueBase(DeclarativeBase):
    pass

def get_estoque_db():
    db = EstoqueSession()
    try:
        yield db
    finally:
        db.close()
```

### `backend/app/models/estoque.py`

```python
from sqlalchemy import Integer, String, Text, CheckConstraint
from sqlalchemy.orm import Mapped, mapped_column
from app.database.estoque_db import EstoqueBase

class Equipamento(EstoqueBase):
    __tablename__ = "equipamentos"
    __table_args__ = (
        CheckConstraint("quantidade >= 0", name="ck_equipamento_quantidade_nao_negativa"),
    )

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    nome: Mapped[str] = mapped_column(String(150), nullable=False)
    descricao: Mapped[str | None] = mapped_column(Text, nullable=True)
    categoria: Mapped[str] = mapped_column(String(100), nullable=False)
    quantidade: Mapped[int] = mapped_column(Integer, nullable=False)
```

## Schema da Tabela

| Campo        | Tipo         | Restrições                          | Descrição                          |
|--------------|--------------|--------------------------------------|------------------------------------|  
| `id`         | INTEGER      | PK, AUTOINCREMENT                    | Identificador único                |
| `nome`       | VARCHAR(150) | NOT NULL                             | Nome do equipamento                |
| `descricao`  | TEXT         | NULLABLE                             | Descrição detalhada                |
| `categoria`  | VARCHAR(100) | NOT NULL                             | Ex.: "Medição", "Segurança"         |
| `quantidade` | INTEGER      | NOT NULL, CHECK (quantidade >= 0)    | Unidades disponíveis               |
