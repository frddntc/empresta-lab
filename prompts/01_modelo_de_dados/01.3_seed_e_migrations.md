# Prompt 01.3 — Inicialização dos Bancos e Seed de Dados

> **Ordem de implementação:** Terceiro sub-prompt do modelo de dados. Implemente após 01.1 e 01.2. Este prompt cria os scripts que inicializam os bancos e populam o estoque inicial.

---

## Objetivo

Criar os scripts responsáveis por inicializar (criar tabelas) no banco configurado — PostgreSQL via `DATABASE_URL` em produção, SQLite local sem ela — e popular a tabela de equipamentos com dados iniciais de laboratório.

---

## Contexto

Os models já foram definidos (Prompts 01.1 e 01.2). Agora precisamos garantir que as tabelas sejam criadas automaticamente na inicialização da aplicação e que o estoque tenha dados de exemplo. O script de inicialização será chamado no evento `startup` do FastAPI (Prompt 02.1).

---

## Escopo

Esta tarefa cobre **exclusivamente**:

- `backend/app/database/init_db.py` — cria todas as tabelas nos dois bancos.
- `backend/app/database/seed_estoque.py` — popula o `estoque.db` com equipamentos de exemplo (idempotente).

---

## Restrições

> ⚠️ **Não altere nada além do que está descrito neste prompt.**
> Não crie rotas, endpoints, modelos, Dockerfiles, testes ou qualquer outro artefato.

- O script de seed deve ser **idempotente**: se os dados já existirem (verificar pela coluna `nome`), não deve inserir duplicatas.
- Usar `Base.metadata.create_all(engine)` para criar as tabelas — sem Alembic.
- Os modelos `Equipamento`, `EstoqueBase`, `EmprestimosBase` devem ser importados antes de chamar `create_all`.
- O seed deve inserir ao menos **5 equipamentos** cobrindo ao menos **2 categorias**.
- A função `init_db()` deve poder ser chamada sem argumentos.

---

## Arquivos a Criar

### `backend/app/database/init_db.py`

```python
from app.database.estoque_db import estoque_engine, EstoqueBase
from app.database.emprestimos_db import emprestimos_engine, EmprestimosBase

# Importar todos os modelos para registrá-los nos metadados
import app.models.estoque  # noqa: F401
import app.models.emprestimos  # noqa: F401

def init_db() -> None:
    """Cria todas as tabelas nos bancos configurados (PostgreSQL via DATABASE_URL,
ou os SQLite locais), se ainda não existirem."""
    EstoqueBase.metadata.create_all(bind=estoque_engine)
    EmprestimosBase.metadata.create_all(bind=emprestimos_engine)
```

### `backend/app/database/seed_estoque.py`

```python
from sqlalchemy.orm import Session
from app.database.estoque_db import EstoqueSession
from app.models.estoque import Equipamento

EQUIPAMENTOS_INICIAIS = [
    {
        "nome": "Paquímetro",
        "descricao": "Instrumento de medição de precisão para dimensões lineares.",
        "categoria": "Medição",
        "quantidade": 5,
    },
    {
        "nome": "Multímetro Digital",
        "descricao": "Medição de tensão, corrente elétrica e resistência.",
        "categoria": "Medição",
        "quantidade": 3,
    },
    {
        "nome": "Osciloscópio",
        "descricao": "Análise e visualização de sinais elétricos.",
        "categoria": "Medição",
        "quantidade": 2,
    },
    {
        "nome": "EPI - Óculos de Proteção",
        "descricao": "Óculos de proteção individual contra respingos e partículas.",
        "categoria": "Segurança",
        "quantidade": 10,
    },
    {
        "nome": "EPI - Luva Química",
        "descricao": "Luvas de proteção contra agentes químicos.",
        "categoria": "Segurança",
        "quantidade": 8,
    },
    {
        "nome": "Termômetro de Infravermelho",
        "descricao": "Medição de temperatura sem contato.",
        "categoria": "Medição",
        "quantidade": 4,
    },
]

def seed_estoque() -> None:
    """Popula a tabela de equipamentos com dados iniciais. Idempotente: não duplica registros."""
    db: Session = EstoqueSession()
    try:
        for dados in EQUIPAMENTOS_INICIAIS:
            existe = db.query(Equipamento).filter_by(nome=dados["nome"]).first()
            if not existe:
                equipamento = Equipamento(**dados)
                db.add(equipamento)
        db.commit()
    finally:
        db.close()
```
