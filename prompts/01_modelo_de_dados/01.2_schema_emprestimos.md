# Prompt 01.2 — Modelos de Clientes e Empréstimos

> **Ordem de implementação:** Segundo sub-prompt do modelo de dados. Implemente após 01.1 e antes de 01.3 (seed) e 01.4 (testes).

---

## Objetivo

Definir os modelos SQLAlchemy e a configuração de sessão para o banco `emprestimos.db`, que armazena os dados dos clientes (incluindo credenciais de acesso) e os registros de empréstimos de equipamentos.

---

## Contexto

Clientes e empréstimos vivem no mesmo banco (PostgreSQL em produção; SQLite no modo local). A FK `emprestimos.cliente_id → clientes.id` é nativa, com `ON DELETE SET NULL`: se um cliente for eventualmente removido da base, os empréstimos devolvidos permanecem como histórico com `cliente_id NULL` (a regra vigente é cadastro permanente — a configuração é defensiva). Como o catálogo de equipamentos é gerenciado pela camada de estoque, `emprestimos.equipamento_id` é uma coluna INTEGER simples (sem FK nativa) e a integridade é garantida pela camada de serviço; `nome_equipamento` é desnormalizado para preservar o histórico.

A tabela `clientes` já inclui o campo `senha_hash` para que a autenticação no backend funcione nativamente sem necessidade de migrações estruturais posteriores.

---

## Escopo

Esta tarefa cobre **exclusivamente**:

- O arquivo `backend/app/database/emprestimos_db.py` — engine, sessão e base declarativa para `emprestimos.db`.
- O arquivo `backend/app/models/emprestimos.py` — models `Cliente` e `Emprestimo`.

## Arquivos a Criar

### `backend/app/database/emprestimos_db.py`

```python
import os
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, DeclarativeBase

# Em Docker, DATABASE_URL aponta para o container PostgreSQL (compose).
# Sem ela (dev local sem Postgres), cai para arquivos SQLite em DATABASE_DIR.
DATABASE_URL = os.getenv("DATABASE_URL")


def _build_engine():
    if DATABASE_URL:
        # PostgreSQL (psycopg2): pool_pre_ping evita usar conexões fechadas
        # pelo servidor após ociosidade.
        return create_engine(
            DATABASE_URL,
            pool_pre_ping=True,
            pool_size=5,
            max_overflow=10,
        )
    database_dir = os.getenv("DATABASE_DIR", "data")
    os.makedirs(database_dir, exist_ok=True)
    return create_engine(
        f"sqlite:///{os.path.join(database_dir, 'emprestimos.db')}",
        connect_args={"check_same_thread": False},
    )


emprestimos_engine = _build_engine()

EmprestimosSession = sessionmaker(autocommit=False, autoflush=False, bind=emprestimos_engine)

class EmprestimosBase(DeclarativeBase):
    pass

def get_emprestimos_db():
    db = EmprestimosSession()
    try:
        yield db
    finally:
        db.close()
```

### `backend/app/models/emprestimos.py`

```python
from datetime import date
from sqlalchemy import Integer, String, Boolean, Date, ForeignKey, CheckConstraint
from sqlalchemy.orm import Mapped, mapped_column, relationship
from app.database.emprestimos_db import EmprestimosBase

class Cliente(EmprestimosBase):
    __tablename__ = "clientes"

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    nome: Mapped[str] = mapped_column(String(200), nullable=False)
    email: Mapped[str] = mapped_column(String(200), nullable=False)
    telefone: Mapped[str] = mapped_column(String(20), nullable=False)
    matricula: Mapped[str] = mapped_column(String(50), nullable=False, unique=True)
    senha_hash: Mapped[str] = mapped_column(String(200), nullable=False)

    emprestimos: Mapped[list["Emprestimo"]] = relationship("Emprestimo", back_populates="cliente")


class Emprestimo(EmprestimosBase):
    __tablename__ = "emprestimos"
    __table_args__ = (
        CheckConstraint("quantidade > 0", name="ck_emprestimo_quantidade_positiva"),
    )

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    # Nullable + ON DELETE SET NULL: quando o cliente é removido da base (regra
    # de negócio pós-devolução), os empréstimos devolvidos permanecem como
    # histórico com cliente_id NULL (imposto pelo PostgreSQL; no SQLite local
    # a FK não é imposta e o id fica órfão, mesmo efeito prático).
    cliente_id: Mapped[int | None] = mapped_column(
        Integer, ForeignKey("clientes.id", ondelete="SET NULL"), nullable=True
    )
    equipamento_id: Mapped[int] = mapped_column(Integer, nullable=False)
    nome_equipamento: Mapped[str] = mapped_column(String(150), nullable=False)
    quantidade: Mapped[int] = mapped_column(Integer, nullable=False)
    data_emprestimo: Mapped[date] = mapped_column(Date, nullable=False, default=date.today)
    prazo_devolucao: Mapped[date] = mapped_column(Date, nullable=False)
    devolvido: Mapped[bool] = mapped_column(Boolean, nullable=False, default=False)
    data_devolucao: Mapped[date | None] = mapped_column(Date, nullable=True)

    cliente: Mapped["Cliente"] = relationship("Cliente", back_populates="emprestimos")
```

## Schema das Tabelas

### Tabela `clientes`

| Campo        | Tipo         | Restrições        | Descrição                              |
|--------------|--------------|-------------------|----------------------------------------|
| `id`         | INTEGER      | PK, AUTOINCREMENT | Identificador único                    |
| `nome`       | VARCHAR(200) | NOT NULL          | Nome completo                          |
| `email`      | VARCHAR(200) | NOT NULL          | E-mail institucional                   |
| `telefone`   | VARCHAR(20)  | NOT NULL          | Telefone / WhatsApp                    |
| `matricula`  | VARCHAR(50)  | NOT NULL, UNIQUE  | Matrícula / RA do aluno                |
| `senha_hash` | VARCHAR(200) | NOT NULL          | Hash bcrypt da senha de acesso ao chat |

### Tabela `emprestimos`

| Campo              | Tipo         | Restrições                  | Descrição                              |
|--------------------|--------------|------------------------------|----------------------------------------|
| `id`               | INTEGER      | PK, AUTOINCREMENT            | Identificador único                    |
| `cliente_id`       | INTEGER      | NULLABLE, FK → clientes.id (ON DELETE SET NULL) | Referência ao cliente; NULL quando o cliente é removido após a devolução (histórico preservado) |
| `equipamento_id`   | INTEGER      | NOT NULL                     | ID do equipamento (integridade garantida pela camada de serviço)    |
| `nome_equipamento` | VARCHAR(150) | NOT NULL                     | Nome desnormalizado para histórico     |
| `quantidade`       | INTEGER      | NOT NULL, CHECK (> 0)        | Quantidade emprestada                  |
| `data_emprestimo`  | DATE         | NOT NULL, default=hoje       | Data do empréstimo                     |
| `prazo_devolucao`  | DATE         | NOT NULL                     | Prazo máximo de devolução              |
| `devolvido`        | BOOLEAN      | NOT NULL, default=False      | Se foi devolvido                       |
| `data_devolucao`   | DATE         | NULLABLE                     | Data efetiva de devolução              |
