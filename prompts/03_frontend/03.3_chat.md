# Prompt 03.3 — Interface de Chat Conversacional

> **Ordem de implementação:** Terceiro sub-prompt do frontend. Implemente após 03.1 e 03.2.

---

## Objetivo

Implementar a interface de chat conversacional para o cliente consultar disponibilidade e solicitar empréstimo de equipamentos de laboratório com o assistente inteligente (Gemini).

---

## Contexto

O endpoint `POST /chat` já foi construído (Prompt 02.5) e espera `{ message: string, history: [{ role, text }] }`. O cliente já está autenticado com token JWT. Este prompt cria a tela interativa de chat com visual moderno, balões de diálogo diferenciados e suporte a feedback de carregamento.

---

## Escopo

Esta tarefa cobre **exclusivamente**:

- `frontend/src/pages/Chat.tsx` — tela principal de chat.
- `frontend/src/components/ChatMessageBubble.tsx` — balão de mensagem (distinção entre cliente e assistente).
- `frontend/src/components/TypingIndicator.tsx` — indicador visual de processamento ("Assistente está digitando...").
- Botão de Logout no topo da tela.

---

## Restrições

> ⚠️ **Não altere nada além do que está descrito neste prompt.**
> Não crie ou modifique rotas do backend, painel administrativo ou testes unitários. Não use formulários rígidos no lugar do chat.

- A conversa **deve** ser em formato de chat (balões).
  - Mensagens do **cliente** alinhadas à **direita** com fundo destacado.
  - Mensagens do **assistente** alinhadas à **esquerda** com tom neutro.
- Exibir uma mensagem inicial de boas-vindas do assistente ao abrir o chat.
- Enviar o histórico de mensagens anteriores no formato exigido pela API.
- Desabilitar botão de envio enquanto a resposta estiver sendo gerada.
- Scroll automático para a mensagem mais recente.

## Estrutura do Componente `Chat.tsx`

```typescript
import React, { useState, useRef, useEffect } from 'react'
import api from '../api/client'
import { useAuth } from '../context/AuthContext'

> Nota: a página de chat NÃO tem botão "Sair" próprio — o logout é o único do header global
> (canto superior direito, `App.tsx`), que desloga e leva à **página inicial**.

interface Message {
  role: 'user' | 'model'
  text: string
}

export const Chat: React.FC = () => {
  const [messages, setMessages] = useState<Message[]>([
    {
      role: 'model',
      text: 'Olá! Sou o assistente do Empresta Lab. Qual equipamento e quantidade você gostaria de solicitar?'
    }
  ])
  const [input, setInput] = useState('')
  const [loading, setLoading] = useState(false)
  const messagesEndRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' })
  }, [messages, loading])

  const handleSend = async (e: React.FormEvent) => {
    e.preventDefault()
    if (!input.trim() || loading) return

    const userMessage = input.trim()
    const newHistory = [...messages, { role: 'user' as const, text: userMessage }]
    setMessages(newHistory)
    setInput('')
    setLoading(true)

    try {
      const response = await api.post('/chat', {
        message: userMessage,
        history: messages
      })
      setMessages([...newHistory, { role: 'model', text: response.data.reply }])
    } catch (err) {
      setMessages([...newHistory, { role: 'model', text: 'Desculpe, ocorreu um erro ao se comunicar com o assistente.' }])
    } finally {
      setLoading(false)
    }
  }

  return (
    <div className="chat-container">
      {/* Cabeçalho (sem botão Sair — logout é o do header global).
          Inclui botão/link "Acompanhar empréstimos" -> /emprestimos
          (página do prompt de Acompanhar empréstimos ativos). */}
      {/* Lista de Mensagens */}
      {/* Input e Botão de Envio */}
    </div>
  )
}
```

## Notas de Implementação

1. **Sem botão "Sair" duplicado:** a versão literal do prompt colocava um "Sair" no cabeçalho do
   chat, duplicando o do header global. A página usa apenas o header global.
2. **Botão "Acompanhar empréstimos":** implementado como `<Link to="/emprestimos" className="btn-ghost
   chat-acompanhar">` no cabeçalho do chat (com `text-decoration: none` via CSS). Teste correspondente
   no `__tests__/Chat.test.tsx`.
2. **Logout do header global leva à home:** no `App.tsx`, o handler faz `logout()` e em seguida
   `window.location.assign('/')` (navegação plena). `navigate('/')` não funciona aqui: ao limpar o
   token, o `ProtectedRoute` da rota atual re-renderiza e redireciona para `/login` antes da
   transição do roteador. Validado em navegador: "Sair" no chat → `http://localhost/`.
