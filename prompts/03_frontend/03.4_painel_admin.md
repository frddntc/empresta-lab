# Prompt 03.4 — Painel Administrativo e Devolução de Empréstimos

> **Ordem de implementação:** Quarto sub-prompt do frontend. Implemente após 03.1 e 03.2.

---

## Objetivo

Implementar a página de Login do Administrador e o Painel Administrativo para auditoria de empréstimos ativos, com indicação de prazo de devolução e ação imediata de baixa/devolução de itens.

---

## Contexto

O backend oferece as rotas `POST /auth/admin/login`, `GET /emprestimos` e `PUT /emprestimos/{id}/devolver` (Prompts 02.2 e 02.4). O administrador precisa de uma interface limpa e intuitiva para monitorar quem está de posse de quais equipamentos e qual o prazo de devolução, podendo registrar a devolução com restauração automática de estoque.

---

## Escopo

Esta tarefa cobre **exclusivamente**:

- `frontend/src/pages/AdminLogin.tsx` — tela de login para administradores (usuário + senha).
- `frontend/src/pages/AdminDashboard.tsx` — tela do painel administrativo com tabela completa de empréstimos.
- Componente visual de indicação de status (No Prazo vs. Vencido).
- Integração com `PUT /emprestimos/{id}/devolver`.
- Registro das rotas `/admin/login` e `/admin` no `App.tsx`.

---

## Restrições

> ⚠️ **Não altere nada além do que está descrito neste prompt.**
> Não implemente o CRUD de equipamentos (pertence ao 03.5), testes ou endpoints do backend.

- A rota `/admin` deve ser protegida exigindo `requiredRole="admin"` no `ProtectedRoute`.
- As credenciais de administrador devem ser enviadas para `POST /auth/admin/login`.
- A lista de empréstimos deve atualizar na tela imediatamente após a devolução.

---

## Arquivos a Criar

### `frontend/src/pages/AdminLogin.tsx`

```tsx
import React, { useState } from 'react'
import { useNavigate } from 'react-router-dom'
import api from '../api/client'
import { useAuth } from '../context/AuthContext'

export const AdminLogin: React.FC = () => {
  const [usuario, setUsuario] = useState('')
  const [senha, setSenha] = useState('')
  const [erro, setErro] = useState<string | null>(null)
  const [carregando, setCarregando] = useState(false)
  const { login } = useAuth()
  const navigate = useNavigate()

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault()
    setErro(null)
    setCarregando(true)

    try {
      const res = await api.post('/auth/admin/login', { usuario, senha })
      login(res.data.access_token, 'admin')
      navigate('/admin')
    } catch (err: any) {
      setErro(err.response?.data?.detail || 'Credenciais de administrador inválidas.')
    } finally {
      setCarregando(false)
    }
  }

  return (
    <div style={{ maxWidth: 400, margin: '80px auto', padding: 24, border: '1px solid #ddd', borderRadius: 8 }}>
      <h2>Painel Administrativo - Acesso</h2>
      {erro && <div style={{ color: 'red', marginBottom: 12 }}>{erro}</div>}
      <form onSubmit={handleSubmit}>
        <div style={{ marginBottom: 16 }}>
          <label style={{ display: 'block', marginBottom: 4 }}>Usuário Admin</label>
          <input
            type="text"
            required
            value={usuario}
            onChange={(e) => setUsuario(e.target.value)}
            style={{ width: '100%', padding: 8, boxSizing: 'border-box' }}
          />
        </div>
        <div style={{ marginBottom: 16 }}>
          <label style={{ display: 'block', marginBottom: 4 }}>Senha</label>
          <input
            type="password"
            required
            value={senha}
            onChange={(e) => setSenha(e.target.value)}
            style={{ width: '100%', padding: 8, boxSizing: 'border-box' }}
          />
        </div>
        <button type="submit" disabled={carregando} style={{ width: '100%', padding: 10 }}>
          {carregando ? 'Entrando...' : 'Entrar como Administrador'}
        </button>
      </form>
    </div>
  )
}
```

### `frontend/src/pages/AdminDashboard.tsx`

> O cabeçalho da página tem apenas o link "Gerenciar Estoque" — o logout fica exclusivamente no
> botão "Sair" do header global (canto superior direito, definido no `App.tsx`), que limpa a sessão
> e leva à **página inicial** da aplicação. Em `/admin/login`, o mesmo header global mostra o botão
> "Voltar" (desautenticado), que leva de volta à home.

```tsx
import React, { useEffect, useState } from 'react'
import { Link } from 'react-router-dom'
import api from '../api/client'
import { useAuth } from '../context/AuthContext'

interface Emprestimo {
  id: int
  cliente_id: int
  equipamento_id: int
  nome_equipamento: string
  quantidade: number
  data_emprestimo: string
  prazo_devolucao: string
  devolvido: boolean
  cliente: {
    id: number
    nome: string
    email: string
    telefone: string
    matricula: string
  } | null
}

export const AdminDashboard: React.FC = () => {
  const [emprestimos, setEmprestimos] = useState<Emprestimo[]>([])
  const [carregando, setCarregando] = useState(true)
  const [mensagem, setMensagem] = useState<string | null>(null)

  const carregarEmprestimos = async () => {
    try {
      setCarregando(true)
      const res = await api.get('/emprestimos')
      setEmprestimos(res.data)
    } catch (err) {
      setMensagem('Erro ao carregar lista de empréstimos.')
    } finally {
      setCarregando(false)
    }
  }

  useEffect(() => {
    carregarEmprestimos()
  }, [])

  const handleDevolucao = async (id: number) => {
    if (!window.confirm('Confirma o registro de devolução deste equipamento?')) return
    try {
      await api.put(`/emprestimos/${id}/devolver`)
      setMensagem('Devolução registrada com sucesso! Estoque restaurado.')
      setEmprestimos(emprestimos.filter((item) => item.id !== id))
    } catch (err: any) {
      alert(err.response?.data?.detail || 'Erro ao registrar devolução.')
    }
  }

  const isVencido = (prazo: string) => {
    const hoje = new Date().toISOString().split('T')[0]
    return prazo < hoje
  }

  return (
    <div style={{ padding: 24, maxWidth: 1100, margin: '0 auto' }}>
      <header style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginBottom: 24 }}>
        <h1>Painel do Administrador - Empréstimos Ativos</h1>
        <div>
          <Link to="/admin/equipamentos" style={{ marginRight: 16 }}>Gerenciar Estoque</Link>
        </div>
      </header>

      {mensagem && <div style={{ padding: 10, background: '#e0f2fe', marginBottom: 16 }}>{mensagem}</div>}

      {carregando ? (
        <p>Carregando empréstimos...</p>
      ) : emprestimos.length === 0 ? (
        <p>Nenhum empréstimo ativo no momento.</p>
      ) : (
        <table style={{ width: '100%', borderCollapse: 'collapse', textAlign: 'left' }}>
          <thead>
            <tr style={{ borderBottom: '2px solid #333' }}>
              <th style={{ padding: 8 }}>Cliente</th>
              <th style={{ padding: 8 }}>Equipamento</th>
              <th style={{ padding: 8 }}>Qtd</th>
              <th style={{ padding: 8 }}>Data Empréstimo</th>
              <th style={{ padding: 8 }}>Prazo Devolução</th>
              <th style={{ padding: 8 }}>Status</th>
              <th style={{ padding: 8 }}>Ação</th>
            </tr>
          </thead>
          <tbody>
            {emprestimos.map((emp) => {
              const vencido = isVencido(emp.prazo_devolucao)
              return (
                <tr key={emp.id} style={{ borderBottom: '1px solid #ddd' }}>
                  <td style={{ padding: 8 }}>
                    <strong>{emp.cliente.nome}</strong>
                    <small style={{ display: 'block' }}>
                      {emp.cliente.matricula} · {emp.cliente.email} · {emp.cliente.telefone}
                    </small>
                  </td>
                  <td style={{ padding: 8 }}><strong>{emp.nome_equipamento}</strong></td>
                  <td style={{ padding: 8 }}>{emp.quantidade}</td>
                  <td style={{ padding: 8 }}>{emp.data_emprestimo}</td>
                  <td style={{ padding: 8 }}>{emp.prazo_devolucao}</td>
                  <td style={{ padding: 8 }}>
                    <span style={{
                      padding: '4px 8px',
                      borderRadius: 4,
                      background: vencido ? '#fee2e2' : '#dcfce7',
                      color: vencido ? '#dc2626' : '#15803d',
                      fontWeight: 'bold'
                    }}>
                      {vencido ? 'Vencido' : 'No Prazo'}
                    </span>
                  </td>
                  <td style={{ padding: 8 }}>
                    <button onClick={() => handleDevolucao(emp.id)} style={{ background: '#2563eb', color: 'white', border: 'none', padding: '6px 12px', borderRadius: 4, cursor: 'pointer' }}>
                      Baixar Devolução
                    </button>
                  </td>
                </tr>
              )
            })}
          </tbody>
        </table>
      )}
    </div>
  )
}
```

## Critérios de Aceite

- [ ] `/admin/login` autentica usuário administrativo e armazena role `"admin"`.
- [ ] Acessar `/admin` sem credenciais de administrador redireciona para login.
- [ ] A tabela exibe lista atualizada de empréstimos em andamento.
- [ ] A tabela NÃO exibe coluna de ID (nem do empréstimo, nem do cliente) — dados de identificação
      numérica ficam apenas no banco.
- [ ] A tabela exibe, para cada empréstimo, os dados fornecidos pelo cliente ao agente — nome em
      destaque e, na linha abaixo, matrícula, email e telefone (vindos do objeto `cliente` da API).
- [ ] O botão "Baixar Devolução" dispara `PUT /emprestimos/{id}/devolver` e atualiza a tabela.
- [ ] O painel NÃO tem botão "Sair" próprio; o logout é o do header global e leva à home.

## Notas de Implementação

1. **Sem botão "Sair" duplicado:** a versão literal do prompt colocava um "Sair" ao lado de
   "Gerenciar Estoque", duplicando o logout do header global. A página usa apenas o header global.
2. **Logout do header global leva à home:** no `App.tsx`, o handler faz `logout()` e em seguida
   `window.location.assign('/')` (navegação plena). Usar `navigate('/')` do roteador não funciona
   aqui: ao limpar o token, o `ProtectedRoute` da rota `/admin` re-renderiza e redireciona para
   `/login` antes da transição do roteador (que é de baixa prioridade), vencendo a navegação.
   Validado em navegador: "Sair" no painel → `http://localhost/`.
3. **Coluna "Cliente" com dados completos:** além do equipamento, cada linha mostra quem está com
   ele — dados fornecidos pelo cliente ao agente (nome, matrícula, email, telefone), vindos do
   objeto `cliente` aninhado na resposta de `GET /emprestimos` (ver Prompt 02.4). Como a devolução
   remove o cliente da base (02.4), o campo pode vir `null` em registros de devolução: a célula
   exibe "Cliente removido da base" nesse caso.
