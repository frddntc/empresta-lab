# Prompt 03.6 — Testes de Interface do Frontend

> **Ordem de implementação:** Sexto e último sub-prompt do frontend. Implemente após 03.1–03.5.

---

## Objetivo

Implementar os testes de componentes automatizados do frontend utilizando **Vitest** e **React Testing Library**, garantindo que as telas críticas (Login, Chat e Rotas Protegidas) funcionem de maneira confiável com chamadas de API mockadas.

---

## Contexto

Todo o frontend e suas rotas já foram implementados (03.1 a 03.5). Este prompt foca exclusivamente na camada de qualidade e cobertura de testes automatizados do lado do cliente.

---

## Escopo

Esta tarefa cobre **exclusivamente**:

- `frontend/src/setupTests.ts` — configuração de ambiente e cleanup para o Testing Library.
- `frontend/src/__tests__/LoginCliente.test.tsx` — teste do formulário de login e submissão.
- `frontend/src/__tests__/Chat.test.tsx` — teste de envio de mensagem e renderização do balão de resposta.
- `frontend/src/__tests__/ProtectedRoute.test.tsx` — teste de proteção de rotas privadas.
- Configuração do script `"test": "vitest run"` no `package.json`.

---

## Restrições

> ⚠️ **Não altere nada além do que está descrito neste prompt.**
> Não modifique arquivos do backend, docker-compose ou o código dos componentes sem estrita necessidade de testabilidade.

- Usar **Vitest**, `@testing-library/react` e `@testing-library/jest-dom`.
- Mockar a instância Axios `api` através de `vi.mock('../api/client')`.
- Não fazer requisições HTTP reais.

### `frontend/src/__tests__/LoginCliente.test.tsx`

```tsx
import { render, screen, fireEvent, waitFor } from '@testing-library/react'
import { describe, it, expect, vi } from 'vitest'
import { BrowserRouter } from 'react-router-dom'
import { LoginCliente } from '../pages/LoginCliente'
import { AuthProvider } from '../context/AuthContext'
import api from '../api/client'

vi.mock('../api/client', () => ({
  default: {
    post: vi.fn(),
  },
}))

describe('Tela de Login do Cliente', () => {
  it('renderiza os campos de matrícula e senha', () => {
    render(
      <AuthProvider>
        <BrowserRouter>
          <LoginCliente />
        </BrowserRouter>
      </AuthProvider>
    )

    expect(screen.getByLabelText(/matrícula/i)).toBeInTheDocument()
    expect(screen.getByLabelText(/senha/i)).toBeInTheDocument()
    expect(screen.getByRole('button', { name: /entrar/i })).toBeInTheDocument()
  })

  it('exibe mensagem de erro ao falhar na autenticação', async () => {
    vi.mocked(api.post).mockRejectedValueOnce({
      response: { data: { detail: 'Credenciais inválidas.' } },
    })

    render(
      <AuthProvider>
        <BrowserRouter>
          <LoginCliente />
        </BrowserRouter>
      </AuthProvider>
    )

    fireEvent.change(screen.getByLabelText(/matrícula/i), { target: { value: 'RA999' } })
    fireEvent.change(screen.getByLabelText(/senha/i), { target: { value: 'errada' } })
    fireEvent.click(screen.getByRole('button', { name: /entrar/i }))

    await waitFor(() => {
      expect(screen.getByText(/credenciais inválidas/i)).toBeInTheDocument()
    })
  })
})
```

### `frontend/src/__tests__/Chat.test.tsx`

```tsx
import { render, screen, fireEvent, waitFor } from '@testing-library/react'
import { describe, it, expect, vi } from 'vitest'
import { BrowserRouter } from 'react-router-dom'
import { Chat } from '../pages/Chat'
import { AuthProvider } from '../context/AuthContext'
import api from '../api/client'

vi.mock('../api/client', () => ({
  default: {
    post: vi.fn(),
  },
}))

describe('Tela de Chat do Cliente', () => {
  it('exibe mensagem inicial de boas-vindas do assistente', () => {
    render(
      <AuthProvider>
        <BrowserRouter>
          <Chat />
        </BrowserRouter>
      </AuthProvider>
    )

    expect(screen.getByText(/sou o assistente do empresta lab/i)).toBeInTheDocument()
  })

  it('envia mensagem e exibe a resposta retornada pela API', async () => {
    vi.mocked(api.post).mockResolvedValueOnce({
      data: { reply: 'Temos 5 paquímetros disponíveis. Deseja prosseguir com o empréstimo?' },
    })

    render(
      <AuthProvider>
        <BrowserRouter>
          <Chat />
        </BrowserRouter>
      </AuthProvider>
    )

    const input = screen.getByPlaceholderText(/digite sua mensagem/i)
    fireEvent.change(input, { target: { value: 'Preciso de um paquímetro' } })
    fireEvent.click(screen.getByRole('button', { name: /enviar/i }))

    await waitFor(() => {
      expect(screen.getByText(/temos 5 paquímetros disponíveis/i)).toBeInTheDocument()
    })
  })
})
```
